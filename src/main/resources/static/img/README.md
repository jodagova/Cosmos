# Imágenes

Colocar aquí los assets del cliente **ya optimizados para web**
(máx. ~1600px de ancho, JPEG/WebP ~80%, idealmente < 300 KB c/u):

- `logo.png` — logo de Cosmos con fondo transparente
- fotos de menú y de ambiente

Referenciar desde las plantillas como `@{/img/nombre.ext}`.

Cuando el personal necesite subir/cambiar fotos por sí mismo, migrar a
almacenamiento externo (Cloudinary) en lugar de commitear al repo.
